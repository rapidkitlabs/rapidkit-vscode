# Workspai VS Code v0.47.0

Released September 6, 2026.

## Local repository intelligence before the first agent change

Workspai for VS Code 0.47.0 is validated against Workspai CLI 0.75.0. The new
Analyze Repo tab turns a public repository URL into a locally generated,
evidence-backed architecture and readiness report before an agent changes the
project.

## What the user receives

An opt-in recorder captures actual panel frames during analysis and a close-up
tour of the rendered results. The recorded 960×600 GIF compresses waiting time
and retains up to 36 frames. Illustrated summaries remain a separate export.
Graph orbit rendering and export use independent canvases, and transparent
edges no longer write depth that can hide endpoint sprites. Remote execution
and security audits without evidence remain unverified.

The report shows canonical project, entity, relation, proof, and diagnostic
counts; detected runtimes and frameworks; the actual intelligence-chain
verdict; highly connected architecture surfaces derived from Graph relations;
and a bounded-retrieval estimate with its CLI-authored claim boundary. It does
not invent a proprietary score or label an important file as dangerous.

The result surface reuses the production 3D Graph renderer and canonical
Doctor evidence projection. Users can export either the real analysis-stage
story or a seamless 360° Graph orbit as a locally encoded GIF.

The Graph is a full-width, architecture-first explorer with text, project,
entity-kind, and neighborhood controls. Evidence-derived decision panels show
Web/remote-agent fit, Doctor-observed security signals, verification and
delivery controls, and high-reach change surfaces with explicit claim
boundaries. The guided Story GIF captures the rendered Graph and walks through
the key result scenes with focused zooms.

Users can inspect the Graph and intelligence artifacts, open the isolated copy
in another VS Code window, or delete all locally retained analysis data.

## Review changes before agent handoff

Review Changes combines the local working-tree comparison with CLI-authored
impact evidence, freshness checks, verification recommendations, and searchable
changed paths. Its copyable handoff preserves scope and impact reasons so a
coding agent receives the evidence behind the change rather than a raw diff
alone.

The review remains honest about its boundary: it requires a Git-rooted Workspai
workspace and an existing intelligence snapshot, does not run project scripts
automatically, and never treats unavailable or mismatched evidence as a pass.

Dashboard is now the first primary tab. Analyze Repo and Review Changes use a
consistent action hierarchy, clearer scope guidance, readable evidence labels,
and keyboard-visible focus states.

## Local-first safety and cost boundary

Quick Analysis accepts only HTTPS repository-root URLs from public GitHub,
GitLab, and Bitbucket. It uses a shallow clone with submodules and LFS smudging
disabled. Workspai HOME, configuration, and registry state are isolated inside
extension storage. The flow does not install project dependencies or execute
repository build, test, start, or lifecycle scripts.

No Workspai-hosted analysis service is required. Network traffic is limited to
the user's direct repository clone and any normal package/runtime resolution
performed by the verified extension runtime.

## Governed AI Agent creation

Create now begins with a product category instead of one flat framework list.
The AI Agent category offers release-admitted Microsoft Agent Framework Python
and .NET kits. Workspai chooses the exact runtime profile from the selected kit,
creates bounded agent context and ownership evidence, and leaves dependency
installation, credentials, and model calls under explicit operator control.

The same executable-kit contract drives primary-sidebar creation, Dashboard
starters, the secondary Create tab, and AI Create. Studio reads the generated
agent identity, bounded context, managed adapter state, and offline verification
boundary instead of applying generic web-service startup advice.

## CLI 0.75.0 alignment

The bundled runtime and published contracts are synchronized with Workspai CLI
0.75.0. The extension consumes the CLI's Agent Framework admission, governed
creation, unified JavaScript/TypeScript runtime family, nested-project topology
boundaries, external caller scopes, and bounded Project Agent Context without
defining parallel semantics.

## Compatibility

- VS Code 1.106.0 or newer
- Workspai CLI 0.75.0 or newer
- Git for Analyze Repo
- RapidKit Core 0.6.0 only for Python-backed kits/modules

Optional terminal installation:

```bash
npm install -g workspai@0.75.0
workspai --version
```
